# TradeOps AI — Vercel Demo

This folder is the static, recruiter-facing demo for the TradeOps AI project.

## Deploy on Vercel

1. Upload this `web` folder to your GitHub repository.
2. In Vercel, import the repository.
3. Framework Preset: **Other**
4. Build Command: **leave empty**
5. Output Directory: **leave empty**
6. Deploy.

The original Python/Streamlit + Isolation Forest implementation remains in the repository's `app.py`.

The browser demo uses deterministic synthetic trading-workflow patterns and an in-browser anomaly scoring visualization. It does not claim to run the Python `sklearn` model in the browser.
